# Casa al día

App web (PWA) para llevar el control de las tareas de limpieza del hogar por estancias y periodicidades.

- Abrir: https://oscargalego.github.io/casa-al-dia/
- En Android: Chrome → menú ⋮ → «Añadir a pantalla de inicio».
- Los datos se guardan en el propio móvil (localStorage). Ajustes → «Enviar» comparte la configuración en JSON.
